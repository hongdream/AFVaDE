# Asynchronous Federated Variational Deep Embedding for Clustering over Heterogeneous Edge Devices
## Intro
This repo contains the code and experiment results of our proposed AFVaDE.
![AFVaDE Architecture](./model_diagram.png)
## Requirements
- pytorch==2.0.1
- numpy==1.25.2
- pandas==2.3.2
- scikit-learn==1.7.2
- scipy==1.15.3
- munkres==1.1.4
## How to run
```shell
python main_async.py --dataset xxx
```
**xxx: select the dataset you want to run.** 
## Example
```shell
python main_async.py --dataset iris
```
